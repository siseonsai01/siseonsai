# 시선사이 모바일 — 전체 음성 생성 대본 (mobile-voice-v1)

아래 "ChatGPT에 붙여 넣을 요청"과 "대본 표"를 그대로 ChatGPT에 넣어 주세요. 파일 이름(id)은 앱이 그대로 찾아 쓰니 바꾸지 마세요.

## ChatGPT에 붙여 넣을 요청

```
아래 표의 대사를 한 줄씩 각각 mp3 파일로 만들어 줘.

[목소리]
- 전부 같은 한 사람 목소리로: 지난번 시선사이 동화책에 쓴, 저장해 둔 그 내레이터 목소리를 그대로 써 줘. 줄마다 목소리를 새로 고르지 마.
- 높낮이(피치)와 빠르기를 줄마다 바꾸지 마. 따뜻한 동화책 읽어 주는 말투, 보통보다 조금 천천히, 만 3~6세 아이가 알아듣게 또박또박.
- 아이에게 하는 말(반말)은 다정하고 밝게, 부모님께 하는 말(존댓말)은 차분하게. 둘 다 같은 목소리.
- 칭찬(praise-child-*)은 정답을 맞힌 것처럼 들리지 않게, "골라 줘서 반가워" 느낌으로.
- 친구 대사(friend-*)는 같은 목소리에서 친구 이름은 또렷하게, 의성어(깡총, 끼룩, 멍, 슝 등)는 살짝 재미있게. 다른 사람 목소리나 캐릭터 성대모사로 바꾸지 마.
- 정리 시범(motion-*)은 3~5초 안에 끝나게, 원래 빠르기 그대로.

[파일]
- 한 줄 = 한 파일. 파일 이름은 표의 id + .mp3 (예: story-0.mp3). 표에 적힌 글자만 읽고, 앞뒤에 인사나 설명을 붙이지 마.
- 앞뒤 무음은 0.2초 안쪽으로 짧게. 44.1kHz 또는 48kHz, 모노, 128kbps 이상 mp3.
- 모두 mobile-voice-v1/ 폴더에 넣고 zip으로 묶어 줘.
- 같은 폴더에 manifest.json도 만들어 줘: [{"id":"story-0","file":"story-0.mp3","text":"(읽은 문장)","seconds":0.0}] 형태로, 표의 순서대로 전부.
- 다 만든 뒤 표의 id가 하나도 빠지지 않았는지, 읽은 문장이 표와 한 글자도 다르지 않은지 확인해 줘.
```

## 요청문 (한 번에)

```
시선사이 모바일 동화 음성을 만든 것과 똑같은 방법·같은 화자·같은 설정으로, 아래 5줄만 mp3로 만들어 줘.
- 화자: 기존 v13 저장 화자(voice_94cruhwim89u), 모델 gemini-3.8-flash-lite-tts, 따뜻하고 활기찬 동화 말투. 예전 Leda가 아니야.
- 목소리를 새로 고르지 말고, 음높이·속도·음량·음색 보정도 하지 마. 아이에게 다정하고 밝게.
- 파일 이름은 앞의 id + .mp3. 오른쪽 문장만 읽고 앞뒤에 아무것도 붙이지 마.
- 형식: 모노, 44.1kHz, 128kbps 이상, 앞뒤 무음 0.2초 이하.
- friend-PVSD는 발음을 꼭 지켜 줘: "각각각"은 [각깍깍]처럼 또렷하게, "다람쥐"는 ㄷ 소리로 [다람쥐] (타람쥐 아님), 마지막 "쏙!"은 끝소리 ㄱ까지 짧고 또렷하게.
- 만든 뒤 각 파일을 받아쓰기로 확인해서, 문장과 다르게 들리는 파일은 다시 만들어 줘. 받아쓰기 결과도 같이 알려 줘.
- 다 만들면 5개를 zip 하나로 묶어 다운로드 링크로 줘. GitHub 작업이나 빌드는 하지 마.
- 같은 화자를 못 쓰거나 결제·한도 초과가 필요하면 만들지 말고 이유만 말해 줘.

zip 이름: siseon-mobile-voice-v15.zip

cover | 안녕, 우리 친구! 여기는 토끼들의 방이야. 우리 친구와 부모님이 좋아하는 걸 서로 알아보는 그림 놀이야! 어떤 걸 선택해도 맞고 틀리는 건 없어. 재미로 우리 집 정리 친구를 만나 보자!
choices-intro | 아래 작은 그림 두 개 중에 골라도 되고, 위 큰 방 그림에서 장난감을 직접 콕 눌러도 돼.
scene-tip | 아래 작은 그림 두 개 중에서 골라 줘!
egg-loading | 친구를 만나러 가요! 알이 준비될 때까지 잠깐만 기다려 줘.
friend-PVSD | 나는 각각각 다람쥐! 도토리처럼 딱! 쓰고 나면 바로 제자리에 쏙!
```

- 표지 자막은 새 음성 길이에 맞춰 글자 수 비율로 자동으로 나뉩니다(`playIntro`).
- 남은 생성 한도는 지난 작업 기준 약 6회로 추산되어 있습니다(VOICE-AUDIT.md). 5줄을 한 번에 요청하면 한도를 아낄 수 있습니다.

# 시선사이 모바일 — 새 음성 22줄만 (3번에 나눠 요청)

태블릿판에서 이미 만든 54줄(이야기·질문·보기·친구·정리 시범·소개)은 같은 화자 녹음이 앱에 들어 있어서 **다시 만들 필요가 없어요.** 모바일에서 새로 생긴 22줄만, 한 번에 7~8줄씩 요청하세요.

받은 zip은 그대로 **다운로드 폴더**에 두면 돼요 (파일 이름 예: `siseon-mobile-voice-1.zip`).

## 1번째 요청 (8줄)

```
시선사이 태블릿판 동화 음성을 만든 것과 똑같은 방법·같은 화자·같은 설정으로, 아래 8줄만 mp3로 만들어 줘.
- 목소리를 새로 고르지 말고, 음높이·속도 보정도 하지 마. 아이에게는 다정하고 밝게.
- 파일 이름은 앞의 id + .mp3. 오른쪽 문장만 읽고 앞뒤에 아무것도 붙이지 마. 앞뒤 무음은 짧게.
- 다 만들면 8개를 zip 하나로 묶어 다운로드 링크로 줘. GitHub 작업이나 빌드는 하지 마.

zip 이름: siseon-mobile-voice-1.zip
```

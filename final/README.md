# 시선사이 · 두 토끼의 방, 두 권의 이야기

2026-11-13 최종 편집 v10을 보관한 원안입니다. PC 실행본과 별도로 클라우드에서 두 태블릿 연결·설문 저장을 처리합니다.

- `app/src/`: 수정 가능한 화면·그림·음성·알깨기 원본
- `app/index.html`: PC 실행용 통합 완성본. 직접 편집하지 않습니다.
- `worker/index.js`: 클라우드 설문 서버
- `drizzle/`: 클라우드 저장소의 구조 변경 이력
- `server.py`: PC에서 실행하는 기존 서버

클라우드용 빌드: `python build_cloud.py` → `dist/`

검증: `node tests/backend.mjs`, `node tests/accessibility.mjs`, `node tests/navigation.mjs`

v9는 아이용 다섯 질문의 왼쪽·오른쪽 그림을 음성으로 읽을 때 해당 보기에 손가락과 테두리를 표시합니다. 매 장의 공통 방 그림 탐색, 알깨기 준비·두드리기, 가족사진 설명을 음성으로 안내합니다. 정리친구 16유형은 이번 선택의 의미와 함께 해 볼 방법을 설명하며, 결과지에는 그래프·선택표 한 개·관찰 의견을 배치합니다. 유형은 한 장면의 체험 기록이며 표준화된 성격·발달 검사가 아닙니다.

v10은 소개 표지와 공통 방 준비 화면을 구분하고, 같은 방을 보는 서로의 생각을 알아보고 가족의 정리 방법을 함께 찾는 설문 목적을 화면과 동화 음성으로 안내합니다. 왼쪽 위 로고는 소개 표지를 열며 연결과 답을 지우지 않습니다. 표지의 시작 버튼은 저장한 책을 이어 엽니다. 실제 태블릿의 스피커 청취 및 실물 A4 출력 검수는 별도로 필요합니다.

두 태블릿은 처음 한 번 연결하며 다음 가족도 같은 연결을 유지합니다. 두 책을 모두 마치면 부모님·아이의 결과와 비교 그래프를 함께 봅니다. 알깨기는 각자의 유형을 따릅니다. 실제 설문 기록·연결용 비밀 주소는 이 저장소에 없습니다. 일반 임시 연결과 이전 가족 기록은 24시간 정리 규칙을 따르며, 고정 링크의 연결과 현재 진행 중인 가족 답은 만료되지 않습니다. 사진은 선택 입력이며 결과지 사진은 해당 기기에만 남습니다.

현재 클라우드 주소: https://siseonsai-family-book.buoyantfig.chatgpt.site

사이트는 로그인 없이 이용하는 공개 사이트입니다. 예전 `trycloudflare.com` 임시 링크는 PC가 켜져 있어야 하므로 상시 운영용으로 쓰지 않습니다.

부모님·아이 고정 링크는 같은 두 태블릿의 연결을 계속 유지합니다. 24시간이 지나도 만료되지 않고 새 가족으로 바꾼 뒤에도 주소가 같습니다. 현재 진행 중인 가족 답은 이 연결과 함께 유지하고, 다음 가족으로 전환한 이전 기록은 기존 24시간 정리 규칙을 따릅니다. 실제 고정 주소와 연결 비밀정보는 저장소에 올리지 않습니다.

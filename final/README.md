# 시선사이 · 두 토끼의 방, 두 권의 이야기

2026-11-13 최종 검토 v7을 보관한 원안입니다. PC 실행본과 별도로 클라우드에서 두 태블릿 연결·설문 저장을 처리합니다.

- `app/src/`: 수정 가능한 화면·그림·음성·알깨기 원본
- `app/index.html`: PC 실행용 통합 완성본. 직접 편집하지 않습니다.
- `worker/index.js`: 클라우드 설문 서버
- `drizzle/`: 클라우드 저장소의 구조 변경 이력
- `server.py`: PC에서 실행하는 기존 서버

클라우드용 빌드: `python build_cloud.py` → `dist/`

서버 검증: `node tests/backend.mjs`

두 태블릿은 처음 한 번 연결하며 다음 가족도 같은 연결을 유지합니다. 두 책을 모두 마치면 부모님·아이의 결과와 비교 그래프를 함께 봅니다. 알깨기는 각자의 유형을 따릅니다. 실제 설문 기록·연결용 비밀 주소는 이 저장소에 없습니다. 서버의 가족 기록과 현장 연결은 마지막 활동 후 24시간 보관 규칙을 유지합니다. 사진은 선택 입력이며 결과지 사진은 해당 기기에만 남습니다.

현재 클라우드 주소: https://siseonsai-family-book.buoyantfig.chatgpt.site

사이트는 로그인 없이 이용하는 공개 사이트입니다. 예전 `trycloudflare.com` 임시 링크는 PC가 켜져 있어야 하므로 상시 운영용으로 쓰지 않습니다.

부모님·아이 고정 링크는 같은 두 태블릿의 연결을 계속 유지합니다. 24시간이 지나도 만료되지 않고 새 가족으로 바꾼 뒤에도 주소가 같습니다. 현재 진행 중인 가족 답은 이 연결과 함께 유지하고, 다음 가족으로 전환한 이전 기록은 기존 24시간 정리 규칙을 따릅니다. 실제 고정 주소와 연결 비밀정보는 저장소에 올리지 않습니다.

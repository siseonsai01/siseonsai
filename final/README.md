# 시선사이 원안 · 최종 검토 v7

상시 운영: https://siseonsai-family-book.buoyantfig.chatgpt.site/app/index.html

`app/src/`는 수정 가능한 화면·그림·음성·알깨기 원본입니다. `app/index.html`은 `python app/build.py`로 재생성하는 PC 실행용 통합 파일입니다. 저장소에는 수정 가능한 원본을 보관합니다.

클라우드 빌드: `python build_cloud.py`

서버 검사: `node tests/backend.mjs`

`worker/index.js`와 `drizzle/`는 클라우드 저장 기능입니다. `server.py`는 기존 PC 실행용 서버입니다.

두 태블릿은 처음 한 번 연결하고, 다음 가족은 부모님 쪽 진행자 메뉴에서 시작합니다. 두 책을 모두 마치면 두 캐릭터·비교 그래프·선택 표를 함께 봅니다. 알깨기와 정리 시범은 각자의 유형을 따릅니다. 아이가 말하는 이유는 보호자나 진행자가 선택적으로 입력하며 자동 녹음하지 않습니다. 가족사진은 결과지 왼쪽 상단에서 선택하고 해당 기기에만 남습니다.

가족 답변과 현장 연결은 마지막 활동 후 24시간 보관 규칙을 유지합니다. 결과가 필요하면 다음 가족을 시작하기 전에 저장하세요. 실제 설문 기록·기기별 연결 비밀정보·내부 작업 문서는 공개 저장소에서 제외했습니다.

상시 운영 사이트는 PC가 꺼져 있어도 두 태블릿 연결과 설문 저장을 처리합니다. 부모님과 아이가 모두 마치면 두 결과·비교 그래프를 함께 확인합니다. 사이트의 로그인 설정은 운영 주소를 확인하세요.

`final/app/src/`에는 최종 화면·그림·음성·16유형 알깨기 원본, `final/worker/`에는 클라우드 설문 서버가 있습니다. 실제 가족 기록과 기기 연결 비밀정보는 저장하지 않습니다.

수정은 `final/`에서 진행합니다. 예전 루트 `app/`과 방 모션 실험은 이전 이력으로 보존했습니다.

# 눈에 띈 곳 콕!

방 그림을 아이소메트릭 3D 디오라마로 보여 주는 인터랙티브 모션 그래픽입니다.
마음에 드는 곳(창문, 책장, 책, 노란 쿠션, 빨간 블록, 세모 지붕 블록, 러그) 하나를 콕 누르면
블록이 깨어나고 → 방 전체가 큐브 조각으로 터지며 폭죽이 올라가고 → 고른 물건 이름이 디코딩되며 나타납니다.

- `index.html` 하나로 동작합니다 (외부 라이브러리 없음, 폰트만 Google Fonts).
- 오른쪽 위 버튼으로 네온 모드 전환.
- `index.html#demo`로 열면 자동 시연.

## 시선사이 앱 (`app/`)

- `app/index.html` — 시선사이 앱 전체가 들어 있는 단일 HTML 파일입니다. 첫 화면에서 **토끼 이야기 듣기**를 누르면 나레이션에 맞춰 오프닝 모션이 재생되고, 끝나면 원래 첫 화면으로 돌아옵니다. **건너뛰기**로 바로 멈출 수 있고, '동작 줄이기' 설정에서는 나레이션만 나옵니다.
- `app/src/` — 고칠 때 쓰는 원본(HTML·CSS·JS·그림·소리). `python app/build.py`로 `app/index.html`을 다시 만듭니다. 자세한 안내는 [`app/EDITING.md`](app/EDITING.md).
- `app/opening-motion.mp4` — 같은 오프닝을 나레이션·자막·마지막 제목까지 넣은 20.5초짜리 영상(1920×1080)입니다.

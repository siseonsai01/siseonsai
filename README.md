# 눈에 띈 곳 콕!

방 그림을 아이소메트릭 3D 디오라마로 보여 주는 인터랙티브 모션 그래픽입니다.
마음에 드는 곳(창문, 책장, 책, 노란 쿠션, 빨간 블록, 세모 지붕 블록, 러그) 하나를 콕 누르면
블록이 깨어나고 → 방 전체가 큐브 조각으로 터지며 폭죽이 올라가고 → 고른 물건 이름이 디코딩되며 나타납니다.

- `index.html` 하나로 동작합니다 (외부 라이브러리 없음, 폰트만 Google Fonts).
- 오른쪽 위 버튼으로 네온 모드 전환.
- `index.html#demo`로 열면 자동 시연.

## 시선사이 앱 (`app/`)

- `app/index.html` — 시선사이 앱 전체가 들어 있는 단일 HTML 파일입니다. 첫 화면은 '놀이를 미리 해 봐요' 카드부터 시작하고, 카드 속 캐릭터를 누르거나 문지르면 간지러워하며 웃습니다.
- `app/src/` — 고칠 때 쓰는 원본(HTML·CSS·JS·그림·소리). `python app/build.py`로 `app/index.html`을 다시 만듭니다. 자세한 안내는 [`app/EDITING.md`](app/EDITING.md).
- `app/opening-motion.mp4` — 예전 토끼 표지 오프닝 영상(20.5초, 나레이션 포함). 앱에서는 표지를 뺐고, 영상 파일만 보관합니다.

## 시선사이 계란 깨기 (`egg/`)

16가지 정리 유형 캐릭터가 알에서 나오는 두드리기 놀이입니다.

- `egg/index.html` — 16개 캐릭터 고르기 화면.
- `egg/01_FHSD.html` ~ `egg/16_FVMB.html` — 캐릭터별 놀이. 화면을 콩콩 두드리면 망치가 알을 치고(빠르게 칠수록 높이 들어 세게 침), 다 깨지면 빛 속에서 캐릭터와 유형 이름이 나옵니다.
- `egg/a/` — 함께 쓰는 그림·소리. 캐릭터 그림은 `hog_유형코드.png`.
- 목소리는 "열어줘 이 알 좀 깨줘" 아이 녹음(`egg/a/egg_call.wav`)만 나옵니다.
